Task: left/right-hand motor imagery with first-person and third-person robot-arm feedback.12 participants,3 sessions/person on consecutive days,4 MI recordings/session; separate resting recordings are not included. Each MI run has40 cues, nominal20/class. All source training-phase files form TRAIN; all online-test-phase files form TEST. People and sessions intentionally occur in both partitions. This preserves published phase semantics, pooled across days/conditions; it does not reproduce the original per-session fitted controller or test unseen participants. No validation is archived.

The original GDF uses generic Channel1-35 labels. Numbered source chanlocs.locs independently supplies the matching32 EEG anatomical names and3 accelerometer names, with author-supplied polar layout. Preserve this indexed mapping, GDF names and physical array order; positions are not claimed as individual measured3D coordinates. Reference/ground were not independently recovered. Accelerometers are excluded and their actual physical units remain unresolved despite GDF voltage prefixes.

MNE applies the native GDF physical/digital calibration and EEG unit multiplier. Cast calibrated volts to float64 before multiplying by1e6. No added filter, resampling, baseline or reference. Store all calibration vectors and native event table. Four-second1000-sample crops start at original769/770 class-cue events at250Hz; do not reconstruct a nominal two-second baseline because actual cue/trial-start timing differs. Original trial-start768 and class-cue event indices/positions are preserved and compared with MNE annotations.

Original source identifiers remain strings, including01-12, native session/condition folders and full recording filename. Keep training/online phase, feedback perspective, source timestamps and original/encoded label. Native GDF demographics are unspecified; only handedness is supplied by the publisher description (participant05 ambidextrous, others right-handed), labelled documented rather than a recovered header field. Original timezone is unknown.
