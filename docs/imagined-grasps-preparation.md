# ImaginedGrasps / BCI Competition 2020 Track 4

Full conversion completed and validated8November2026. Classify cylindrical, spherical and lumbrical imagined grasps from the original OSF Track4 collection, a different recording task from ImaginedCommands/Track3 and WalkingTargets/Track5. A common competition paper/project does not imply these are identical recordings or prove separate participant cohorts.

Original [OSF project](https://osf.io/pq7vb/) data licence CC BY 4.0 verified through its own project/licence API. [Pinned file versions and SHA256](imagined-grasps-source-lock.json): 49 files, 5.811 GB. No original dataset DOI independently established. Reference paper: Jeong et al. (2022), *2020 International brain-computer interface competition: A review*, [DOI10.3389/fnhum.2022.898300](https://doi.org/10.3389/fnhum.2022.898300).

Fifteen participants, three recording days separated by seven days. Original day1 training and day2 validation are merged in that order into archive TRAIN; original day3 remains TEST. All 15 people intentionally appear in both partitions: session transfer, not unseen-participant evaluation. No archived validation. Verified totals:4,500train /2,250test,150native epochs/day/person,45recordings and45participant-days.

The organiser's PDF was read and all four pages visually inspected. Its numbered sensor table agrees exactly with native epo.clab/mnt.clab: 60 EEG channels in source order, not guessed names or a generated montage. Native mnt x/y/pos_3d values are retained without asserting coordinate units/frame or individual measured positions. Reference FCz and ground Fpz are documented in the original PDF. Native sampling is 250 Hz; the description reports acquisition at 250 Hz and a 60 Hz notch. No further filter, resampling, baseline or reference is applied.

Native epo.x has shape `(2501,60,150)` and epo.t runs from -6000 to +4000 ms in 4 ms steps. Motor imagery starts at native local sample 1500, where t=0. Keep exactly `epo.x[1500:2500]`, 1,000 samples, t=0..3996 ms; end-exclusive4000 ms. Test indices750:1500 are deliberately zeroed visual-cue data, confirmed in actual files and the reupload README. Exclude cue/rest consistently from all phases; do not feed the zeroed interval to flat-channel removal or create a synthetic continuous timeline.

Train/validation class definitions come from native className/y and the organiser's row mapping. Actual test True Label workbook supplies0/1/2 labels, independently checked against pinned MOABB vectors. The root answer_sheet_track4.xlsx is a prediction template, misleadingly containing a Track5 sheet; it is not ground truth. Encoded archive1/2/3 maps Cylindrical/Spherical/Lumbrical. Keep original one-hot vectors or original true-label cell IDs separately.

Preserve native float64 numeric values unchanged. Microvolt interpretation is inferred from MATLAB EEG convention and amplitudes; an explicit unit is absent. Test epo.resolution has more entries than the 60 selected inputs; retain it as unresolved source metadata, not a guessed per-channel scaling factor. Original continuous offsets, calendar dates, per-session run IDs and individual demographics are missing. Session IDs day1/day2/day3 are linked to organiser folders and documented as such.

Original PDF inconsistencies are retained: introduction/file list says15 subjects but one paragraph says10; the handedness sentence is awkward and individual handedness is not invented; a narrative electrode list differs from the actual numbered table, so native labels and that table determine order. Actual source file membership and shapes are authoritative for conversion counts.

Every float64 case passed exact .ts readback and aligned metadata/label/hash checks. Native60sensor names/order and montage values agree across all45recordings. No flat/tiny EEG channels were removed; no exact duplicates within or across partitions. Aeon loaded both partitions and fit/predict passed on3cases/class/split.
